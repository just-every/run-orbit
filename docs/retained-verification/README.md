# Retained historical verification

The reports and screenshots beside this file were moved byte-for-byte from the
tracked `verification/` tree at `2cbe6479e14e71152af4a21d33b4e70d339ef482`.
Their original contents, dates and relative layout are preserved. Paths written
inside those historical files describe their original execution context.

These are retained source evidence, not results for the current candidate. The
verifier never reads them. Fresh reports, browser evidence and full-capacity
receipts are written to the ignored root `verification/` directory, which is reset
when verification starts. Source checks continue to protect the historical bytes
here while runtime producers can replace their own outputs without modifying any
tracked receipt. The original `visual/` review images also remain unchanged;
current Worker proof screenshots are now generated under `verification/ui/`.

acceptance obligations.
