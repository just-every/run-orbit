# Orbit delivery artifact

`rer-project.json` declares the canonical project `just-every/orbit` and its public source repository `just-every/run-orbit`. Admission supplies the immutable revision separately; a descriptor cannot contain its own commit hash.

Base's maintained delivery producer is exported to `scripts/delivery/base/`. Its `packaging.json` is the source policy for the project descriptor, setup digest, managed workflow and schema-2 artifact. The workflow pins trusted delivery to an immutable revision and requires full verification. It uses Node 22.20.0 and pnpm 10.12.4. Build with `rer build`, then `node scripts/build-delivery-artifact.mjs`; the artifact command packages the emitted build without rebuilding it. Packaging refuses a nonempty output directory. Trusted delivery verifies the source checkout and attests its artifact independently.

The artifact contains raw Worker and asset payload files with sizes and SHA-256 digests, exact existing SQL migrations, one D1 database, Node compatibility and the minute timer. No owner data or private setting is embedded. `rer-setup.json` is the canonical installer manifest; the descriptor binds its exact bytes. Native `/auth/bootstrap` claims a single initial owner with its private setup token and refuses any second claim. Outbox sign-in remains the local native authority until the separate operator-auth migration.

The Worker delegates public build assets to `ASSETS` when owner deployment runs the Worker first. Native document/API/function session checks remain authoritative. `/health` reports database readiness and the actual source SHA, fingerprint and version metadata injected by the deploy kit; local runs have no deployment identity. Unchanged repeat deployments retain data and secrets. A provider-side identity change still requires explicit reconciliation.

The optional Base editor is mounted only under the native app shell. Every grant rechecks the current session and setup-owner row. Grants expire in 30 seconds; the shell renews them against current native authority before expiry. Logout revokes immediately, failed renewal removes the editor and focus rechecks authority. Missing management configuration leaves the optional editor disabled. Application responses deny framing and allow editor frames only from the exact configured management origin. The service must independently authorize its installation and send its own registered `frame-ancestors`; local fixture proof is not hosted service acceptance.

Export integration source from an immutable commit using `scripts/delivery/base/generators/integration.mjs` or the service-owned `scripts/projects/integrations.mjs export`. Adopt the resulting bundle in an authorized service checkout and run `node scripts/projects/integrations.mjs check --id orbit`. This checks the source inventory and adoption revision, not provider credentials or hosted deployment.

Recovery preserves full D1 backups and applied migration bytes. Native archives exclude sessions, delegation authority and source/provider credentials. Restore to fresh resources, compare records, revoke old authority and reconnect excluded secrets before switching traffic.
