## Implementation and boundaries

The current full-operator boundary protects catalog reads and writes and all deal quote operations. Product maintenance is under Settings, and the deal details panel creates and displays immutable versions. Price revisions are append-only; each quote stores its product name, price identity, book price, actual price, override reason, quantities, discounts, tax disclosure and integer-cent totals. Discounts apply before tax; added and inclusive tax round once to the nearest cent with halves rounded up. Not-collected treatment requires zero rate and an explicit disclosure. All authoring and refusal paths leave deal value, stage, forecast, mail and other sales state alone.

A unique deal and version constraint permits only one competing edit to create the next version. Review and progression compare the requested version with the current version before doing anything. Current review returns the exact snapshot plus unresolved DocuSign setup. There is no signature, customer send, provider dispatch, approval, payment or billing transition in this implementation.

Quote dates and prices enter the existing observed evidence set with authenticated links to each version. The conflict model receives only the exact previewed evidence. Its instructions distinguish a superseding version from an actual contradiction and distinguish expiration from kickoff. Existing citation validation and proposed-task behavior stay intact. Only the model HTTP edge is replaced in the proof.

Migration 0081 adds product, book-price and quote-version tables plus immutable-update triggers. Native source generations retain complete pre-quote compatibility; folded archives include all three tables without increasing the base table allowance.
