Unconfirmed or deliberately unclaimed:

- No authenticated provider consoles were available for a live click-through, actual connection, DNS propagation, account approval, paid call or AI billing receipt. Controls were cross-checked with the providers' public documentation; account-specific permissions and console variants still depend on the owner's account.
- Slack's current group_archive documentation describes RTM, not an Events API bot subscription. No instruction tells users to subscribe to that legacy-only event. Existing runtime pre-post channel checks remain intact. App-uninstall/token-revocation handling remains unchanged; this round does not claim whole-clause safety proof.
- The exact Twilio onboarding navigation varies between its new and legacy consoles. The guide identifies both, uses current Voice setup for new accounts, and explicitly qualifies the legacy Phone Numbers path.
- An old Cloudflare Email Workers documentation URL was unavailable through the web tool. The current documented Email Service routing/subdomain pages resolved and were used instead.
- The 12ui CLI installed and the improve command was attempted on a non-secret baseline screenshot, but returned account sign-in required. No hosted design or approved image was obtained. Implementation reuses Orbit's existing native disclosure/form styling.

No step depends on a private held-out gate, another repository checkout, account secret, invented provider scope, or a test-only connection in product code.
